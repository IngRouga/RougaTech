Questions fréquentes

    

      
Faut-il savoir coder pour commencer ?
Le programme commence par les bases du web et du HTML, puis avance module par module jusqu'à la mise en ligne. Pour savoir si la formation correspond à votre niveau, écrivez-nous sur WhatsApp.

      
Est-ce qu'on utilise WordPress ?
Non. Vous apprenez à créer vos sites en code (HTML, CSS et JavaScript), ce qui vous donne des sites rapides et entièrement sur mesure.

      
De quoi ai-je besoin ?
D'un ordinateur et d'une connexion internet pour coder confortablement. La formation se suit en ligne.

      
Le nom de domaine est-il inclus ?
Le nom de domaine s'achète séparément, pour vous ou pour chaque client. Le module 5 vous montre comment le choisir et le relier à votre site.
